# Prime Number Check

## Problem Statement
Given a positive integer, determine whether it is a prime number. A prime number is greater than 1 and has no divisors other than 1 and itself.

## Examples

| Input | Output | Reason |
|-------|--------|--------|
| `2` | `true` | Divisible only by 1 and 2 |
| `7` | `true` | Divisible only by 1 and 7 |
| `13` | `true` | Divisible only by 1 and 13 |
| `1` | `false` | 1 is not prime by definition |
| `4` | `false` | Divisible by 2 |
| `100` | `false` | Divisible by 2, 4, 5, etc. |
