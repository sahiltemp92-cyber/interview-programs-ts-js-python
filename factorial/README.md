# Factorial of a Number

## Problem Statement
Given a non-negative integer `n`, compute its factorial. The factorial of `n` (written `n!`) is the product of all positive integers from 1 to `n`. By convention, `0! = 1`.

> Formula: n! = n × (n-1) × (n-2) × ... × 1

## Examples

| Input (n) | Calculation | Output |
|-----------|-------------|--------|
| `0` | (by convention) | `1` |
| `1` | 1 | `1` |
| `5` | 5×4×3×2×1 | `120` |
| `6` | 6×5×4×3×2×1 | `720` |
| `10` | 10×9×...×1 | `3628800` |
