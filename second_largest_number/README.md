# Second Largest Number in an Array

## Problem Statement
Given an array of integers, find and return the second largest unique number. If no such number exists, return `-1`.

## Examples

| Input | Output |
|-------|--------|
| `[10, 20, 4, 45, 99]` | `45` |
| `[1, 2, 3, 4, 5]` | `4` |
| `[5, 5, 5]` | `-1` |
| `[12, 35, 1, 10, 34, 1]` | `34` |
