# Convert HashMap Keys/Values to a List

## Problem Statement
Given a HashMap, extract its keys into one list and its values into another list. Print both lists separately.

## Example

**Input:**
```
{ "apple": 1, "banana": 2, "cherry": 3 }
```

**Output:**
```
Keys List:   [apple, banana, cherry]
Values List: [1, 2, 3]
```
