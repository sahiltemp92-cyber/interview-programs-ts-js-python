# Iterate Through a HashMap / Dictionary

## Problem Statement
Given a HashMap (or Dictionary), iterate through it and print each key-value pair using at least **two different** iteration approaches.

## Example

**Input:**
```
{ "name": "Alice", "age": "30", "city": "Mumbai" }
```

**Output — Approach 1 (entrySet / items()):**
```
name -> Alice
age -> 30
city -> Mumbai
```

**Output — Approach 2 (keySet / keys()):**
```
name: Alice
age: 30
city: Mumbai
```
