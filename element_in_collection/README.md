# Check if an Element Exists in a Collection

## Problem Statement
Given a collection (List/Array) and a target element, check whether the target element is present. Return `true` or `false`.

## Examples

| Collection | Target | Output |
|------------|--------|--------|
| `[1, 2, 3, 4, 5]` | `3` | `true` |
| `["apple", "banana", "cherry"]` | `"mango"` | `false` |
| `[10, 20, 30]` | `20` | `true` |
| `[]` | `1` | `false` |
