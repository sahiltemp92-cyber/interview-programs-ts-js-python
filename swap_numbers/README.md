# Swap Two Numbers Without a Third Variable

## Problem Statement
Given two integers, swap their values without using a temporary (third) variable. Use arithmetic or XOR operations.

## Examples

| Input A | Input B | Output A | Output B |
|---------|---------|----------|----------|
| `5` | `10` | `10` | `5` |
| `100` | `200` | `200` | `100` |
| `0` | `7` | `7` | `0` |
| `-3` | `3` | `3` | `-3` |
