# Reverse a Number

## Problem Statement
Given an integer, return the number with its digits in reversed order. Handle negative numbers by reversing the absolute value and reapplying the sign.

## Examples

| Input | Output |
|-------|--------|
| `12345` | `54321` |
| `1200` | `21` |
| `-456` | `-654` |
| `7` | `7` |
| `100` | `1` |
