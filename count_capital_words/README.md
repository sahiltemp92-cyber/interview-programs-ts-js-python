# Count Capitalized Words in a String

## Problem Statement
Given a sentence, count how many words start with a capital (uppercase) letter.

## Examples

| Input | Output |
|-------|--------|
| `"Hello World"` | `2` |
| `"Java is Great for Automation"` | `3` |
| `"all lowercase here"` | `0` |
| `"One Two Three four five"` | `3` |
