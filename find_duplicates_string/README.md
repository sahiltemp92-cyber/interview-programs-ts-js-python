# Find Duplicate Characters in a String

## Problem Statement
Given a string, find and print all characters that appear more than once along with their occurrence count.

## Examples

**Input:** `"programming"`
```
Output:
r -> 2
g -> 2
m -> 2
```

**Input:** `"aabbcc"`
```
Output:
a -> 2
b -> 2
c -> 2
```

**Input:** `"hello"`
```
Output:
l -> 2
```
