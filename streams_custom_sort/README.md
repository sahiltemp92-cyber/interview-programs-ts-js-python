# Custom Sorting and Filtering Using Streams / Functional Methods

## Problem Statement
Given a list of integers, use Streams (Java) or functional methods (JS/TS/Python) to:
1. **Filter** only even numbers
2. **Sort** in descending order
3. **Return** the result

## Examples

| Input | Filter Evens | Sort Desc | Output |
|-------|-------------|-----------|--------|
| `[5, 3, 8, 1, 4, 7, 2, 6]` | `[8, 4, 2, 6]` | ↓ | `[8, 6, 4, 2]` |
| `[10, 15, 20, 25, 30]` | `[10, 20, 30]` | ↓ | `[30, 20, 10]` |
| `[1, 3, 5, 7]` | `[]` | ↓ | `[]` |
