# Reverse an Array

## Problem Statement
Given an array of integers, return the array in reverse order without using built-in reverse methods.

## Examples

| Input | Output |
|-------|--------|
| `[1, 2, 3, 4, 5]` | `[5, 4, 3, 2, 1]` |
| `[10, 20, 30]` | `[30, 20, 10]` |
| `[7]` | `[7]` |
| `[1, 2]` | `[2, 1]` |
