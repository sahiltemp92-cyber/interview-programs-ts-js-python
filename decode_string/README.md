# Decode an Encoded String

## Problem Statement
Given an encoded string in the format `"a2b3c4"`, decode it by repeating each character the specified number of times.

## Examples

| Input | Output |
|-------|--------|
| `"a2b3c4"` | `"aabbbcccc"` |
| `"x1y2z3"` | `"xyyzzz"` |
| `"m3n1"` | `"mmmn"` |
| `"p4q2"` | `"ppppqq"` |
