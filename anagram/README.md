# Check if Two Strings are Anagrams

## Problem Statement
Given two strings, determine whether they are anagrams of each other. Two strings are anagrams if they contain the same characters in the same frequency, regardless of order.

## Examples

| Input A | Input B | Output |
|---------|---------|--------|
| `"listen"` | `"silent"` | `true` |
| `"hello"` | `"world"` | `false` |
| `"triangle"` | `"integral"` | `true` |
| `"abc"` | `"cba"` | `true` |
| `"rat"` | `"car"` | `false` |
