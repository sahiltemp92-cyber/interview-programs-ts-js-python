# Sort an Array

## Problem Statement
Given an array of integers, sort it in ascending order. Implement your own sorting logic (e.g., Bubble Sort or Selection Sort) without using built-in sort functions.

## Examples

| Input | Output |
|-------|--------|
| `[64, 34, 25, 12, 22, 11, 90]` | `[11, 12, 22, 25, 34, 64, 90]` |
| `[5, 1, 4, 2, 8]` | `[1, 2, 4, 5, 8]` |
| `[3, 3, 1, 2]` | `[1, 2, 3, 3]` |
| `[1]` | `[1]` |
