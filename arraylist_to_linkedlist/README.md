# Convert ArrayList to LinkedList and Vice Versa

## Problem Statement
Given an ArrayList, convert it to a LinkedList. Then convert the LinkedList back to an ArrayList. Print the type and contents at each step.

## Example

**Input (ArrayList):** `[10, 20, 30, 40, 50]`

**After conversion to LinkedList:**
```
LinkedList: [10, 20, 30, 40, 50]
```

**After converting back to ArrayList:**
```
ArrayList: [10, 20, 30, 40, 50]
```
