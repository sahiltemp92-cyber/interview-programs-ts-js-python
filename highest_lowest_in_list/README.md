# Find Highest and Lowest Values in a List

## Problem Statement
Given a list of integers, find and return the maximum (highest) and minimum (lowest) values **without** using built-in max/min functions.

## Examples

| Input | Max | Min |
|-------|-----|-----|
| `[3, 1, 4, 1, 5, 9, 2, 6]` | `9` | `1` |
| `[100, 200, 50, 75]` | `200` | `50` |
| `[-5, -1, -10, -3]` | `-1` | `-10` |
| `[42]` | `42` | `42` |
