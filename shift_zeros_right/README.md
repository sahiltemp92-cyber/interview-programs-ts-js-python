# Shift All Zeros to the Right of an Array

## Problem Statement
Given an array of integers, move all zeros to the end while maintaining the relative order of non-zero elements. Do this in-place.

## Examples

| Input | Output |
|-------|--------|
| `[0, 1, 0, 3, 12]` | `[1, 3, 12, 0, 0]` |
| `[1, 0, 2, 0, 3]` | `[1, 2, 3, 0, 0]` |
| `[0, 0, 1]` | `[1, 0, 0]` |
| `[1, 2, 3]` | `[1, 2, 3]` |
