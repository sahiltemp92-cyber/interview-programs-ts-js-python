# Replace a Specific Element in an ArrayList

## Problem Statement
Given an ArrayList and a target element, replace **all occurrences** of the target with a new specified replacement value.

## Examples

| Input List | Target | Replacement | Output |
|------------|--------|-------------|--------|
| `[1, 2, 3, 2, 4]` | `2` | `99` | `[1, 99, 3, 99, 4]` |
| `["a", "b", "a"]` | `"a"` | `"z"` | `["z", "b", "z"]` |
| `[5, 5, 5]` | `5` | `0` | `[0, 0, 0]` |
| `[1, 2, 3]` | `9` | `0` | `[1, 2, 3]` (no change) |
