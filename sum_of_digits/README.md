# Sum of Digits of an Integer

## Problem Statement
Given a positive integer, calculate and return the sum of all its individual digits.

## Examples

| Input | Calculation | Output |
|-------|-------------|--------|
| `123` | 1+2+3 | `6` |
| `9999` | 9+9+9+9 | `36` |
| `0` | 0 | `0` |
| `100` | 1+0+0 | `1` |
| `4567` | 4+5+6+7 | `22` |
