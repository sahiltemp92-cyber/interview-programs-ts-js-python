# Insert an Element at the End of a LinkedList

## Problem Statement
Given a LinkedList and a value, insert the value at the **end** of the list. Print the list before and after insertion.

## Examples

**Example 1:**
- Before: `[10, 20, 30]`
- Insert: `40`
- After:  `[10, 20, 30, 40]`

**Example 2:**
- Before: `[]` (empty list)
- Insert: `5`
- After:  `[5]`

**Example 3:**
- Before: `["apple", "banana"]`
- Insert: `"cherry"`
- After:  `["apple", "banana", "cherry"]`
