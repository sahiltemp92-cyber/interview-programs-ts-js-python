# Reverse an ArrayList

## Problem Statement
Given a list of elements, reverse it **without** using any built-in reverse method. Return or print the reversed list.

## Examples

| Input | Output |
|-------|--------|
| `[1, 2, 3, 4, 5]` | `[5, 4, 3, 2, 1]` |
| `["a", "b", "c"]` | `["c", "b", "a"]` |
| `[10]` | `[10]` |
| `[7, 8]` | `[8, 7]` |
