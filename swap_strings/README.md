# Swap Two Strings Without a Third Variable

## Problem Statement
Given two strings, swap their values without using a temporary (third) variable.

## Examples

| Input A | Input B | Output A | Output B |
|---------|---------|----------|----------|
| `"hello"` | `"world"` | `"world"` | `"hello"` |
| `"foo"` | `"bar"` | `"bar"` | `"foo"` |
| `"Java"` | `"Python"` | `"Python"` | `"Java"` |
