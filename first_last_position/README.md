# First and Last Position of a Number in an Array

## Problem Statement
Given a sorted array and a target number, find the first and last positions (indices) of the target. Return `[-1, -1]` if the target is not found.

## Examples

| Input Array | Target | Output |
|-------------|--------|--------|
| `[5, 7, 7, 8, 8, 10]` | `8` | `[3, 4]` |
| `[5, 7, 7, 8, 8, 10]` | `6` | `[-1, -1]` |
| `[1, 1, 1, 1]` | `1` | `[0, 3]` |
| `[2, 4, 6, 8]` | `4` | `[1, 1]` |
