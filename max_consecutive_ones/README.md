# Maximum Consecutive Ones in an Array

## Problem Statement
Given a binary array (containing only 0s and 1s), find the maximum number of consecutive 1s.

## Examples

| Input | Output |
|-------|--------|
| `[1, 1, 0, 1, 1, 1]` | `3` |
| `[1, 0, 1, 1, 0, 1]` | `2` |
| `[0, 0, 0]` | `0` |
| `[1, 1, 1, 1]` | `4` |
