# Print 1 to 100 Without Using Any Loop

## Problem Statement
Print numbers from 1 to 100 **without using** any loop constructs (`for`, `while`, `do-while`). Use recursion or other techniques instead.

## Constraint
> No `for`, `while`, or `do-while` loops are allowed.

## Expected Output
```
1
2
3
4
...
99
100
```
