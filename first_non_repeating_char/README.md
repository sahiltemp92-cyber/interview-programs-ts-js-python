# First Non-Repeating Character in a String

## Problem Statement
Given a string, find the first character that does not repeat anywhere in the string. If all characters repeat, return `-1` or `null`.

## Examples

| Input | Output |
|-------|--------|
| `"swiss"` | `w` |
| `"aabbcc"` | `-1` |
| `"programming"` | `p` |
| `"aabb"` | `-1` |
| `"leetcode"` | `l` |
