# Remove Duplicates from an Array

## Problem Statement
Given an array of integers, remove duplicate values and return only the unique elements (preserving the order of first occurrence).

## Examples

| Input | Output |
|-------|--------|
| `[1, 2, 2, 3, 4, 4, 5]` | `[1, 2, 3, 4, 5]` |
| `[10, 10, 10]` | `[10]` |
| `[5, 3, 1, 3, 5]` | `[5, 3, 1]` |
| `[1, 2, 3]` | `[1, 2, 3]` |
