# Check if a String is a Palindrome

## Problem Statement
Given a string, check whether it reads the same forwards and backwards (ignoring case). Return `true` if it is a palindrome, `false` otherwise.

## Examples

| Input | Output |
|-------|--------|
| `"racecar"` | `true` |
| `"hello"` | `false` |
| `"Madam"` | `true` |
| `"level"` | `true` |
| `"OpenAI"` | `false` |
